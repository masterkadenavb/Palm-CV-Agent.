# Palm-CV-Agent.
This repository contains a Palm Computer Vision Agent designed to accept a defined image input.
1. This requires the OPENCV package. instal using (pip install opencv-contrib-python).
2. Make sure that your palm images are in the same folder as the project.
3. Open terminal and CD to the directory where the Python file is.
4. Paste any of these commands to test different cases:

   
 python3 CVpalm.py/R.png
 python3 CVpalm.py/t.jpg
 python3 CVpalm.py /y.jpeg
 python3 CVpalm.py/u.jpg

 That is it!
